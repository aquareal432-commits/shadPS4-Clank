# ShadPS4 (Ratchet & Clank 2016 Fork)

> A Fork of ShadPS4 that is for Ratchet & Clank (2016)

---

### 🌐 About / Hakkında

**English**  
This is an fork of PS4 Emulator ShadPS4.  
This fork was made to run Ratchet & Clank (2016) Better on ShadPS4.  
Using this on other games might cause problems. Only use for Ratchet & Clank.

---

**Turkish**  
Bu ShadPS4 Emulatörü için bir çatallamadır.  
Bu Çatallama(fork) Ratchet & Clank (2016) ShadPS4 de daha iyi çalıştırmak için yapılmıştır.  
Bu Çatallamayı başka oyunlarda kullanmak sorunlara yol açabilir. Yalnızca Ratchet & Clank için kullanınız.

---

### ⚙️ Recommended Settings / Önerilen Ayarlar

| Setting (English) | Ayar (Türkçe) | Value / Değer |
| :--- | :--- | :--- |
| **ReadBack Mode** | ReadBack Mode | `Relaxed` |
| **Enable Readback Linear Images** | Enable Readback Linear Images | `True` |
| **Enable Direct Memory Access** | Enable Direct Memory Access | `True` |
| **Enable Shader Cache** | Enable Shader Cache | `True` |
| **Red Zone Protection** | Red Zone Protection | `Static Patching` |

### Notes / Notlar

* **Note:** This fork of the emulator was tested on the base release version 1.0. If you get any issue's on the latest version try downgrading or sending an issue so i can take a look.
* **Not:** Bu emulatör çatallaması oyunun çıkış sürümü olan 1.0 'da denenmiştir. Son sürümde herhangi bir hata alıyorsanız sürümü düşürmeyi deneyin veya bir issue gönderin.
